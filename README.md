📸 Photo Resizer

Project Description

Photo Resizer is a simple application that allows users to resize images to their required dimensions. It helps users reduce image dimensions and file size while maintaining good image quality.

Features

- Upload images.
- Resize images to custom dimensions.
- Maintain image quality.
- Support multiple image formats.
- Download resized images.
- Simple and user-friendly interface.

Technologies Used

- Python
- Pillow (PIL)
- Streamlit (if used)

Installation

Install the required libraries:

pip install pillow streamlit

How to Run

streamlit run app.py

How It Works

1. Upload an image.
2. Enter the required width and height.
3. Click the Resize button.
4. Preview the resized image.
5. Download the resized image.

Project Objective

The main objective of this project is to provide an easy and efficient way to resize images according to user requirements.
